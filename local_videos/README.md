# Положите сюда тестовые видео для автозагрузки в MinIO (backend → local_videos API).

Форматы: `.mp4`, `.webm`, `.m4v`

Именование (по желанию):
- `row_1.mp4`, `row_2.mp4` — привязка к номеру ряда
- или просто по алфавиту — файлы раздаются по порядку на число рядов

Видеофайлы в git не попадают (см. `.gitignore`). На сервере после `git pull` скопируйте ролики в эту папку или через SFTP.
